# Glossary

| Term | Meaning |
| --- | --- |
| SOS report | A distress submission; receipt means it was durably recorded, independent of assignment. |
| Check-in | A citizen safety update separate from SOS history. |
| Incident | An operator-created record for coordinated review/work. |
| Verification | Assessing evidence and uncertainty while retaining the original report. |
| Corroboration | Support from independent evidence, distinguished from retries or copied observations. |
| Rescue assignment | A dispatcher-to-responder handoff, pending until confirmed. |
| Rescue mission | Proposed lifecycle for an approved simulated response with tracking and resolution. |
| Provenance | Source, time, transformation and authority of an observation. |
| Idempotency | Repeating the same scoped operation has the same intended effect. |
| LLM agent | Model-directed advisory workflow with bounded, authorized tools and typed state. |
| LangGraph | Proposed state-graph orchestration framework. |
| VRP / CVRP | Vehicle Routing Problem and its capacity-constrained variant. |
| OSMnx | Proposed toolkit for extracting and modeling OpenStreetMap road graphs. |
| PostGIS | Proposed spatial extension for PostgreSQL. |
| CRS | Coordinate reference system used to interpret positions and geometry. |
| OD matrix | Origin–destination travel cost or time matrix. |
| PWA | Progressive web application; the current shell has a service worker but no complete offline outbox. |
