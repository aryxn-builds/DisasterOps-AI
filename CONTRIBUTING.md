# Contributing

Read the [README](README.md) to set up the local environment and the [documentation index](docs/README.md) to find relevant contracts. Use synthetic data and the checked-out branch as implementation evidence. Review existing changes before editing.

Describe the issue, affected module, expected behavior and regression checks. Follow [development guidelines](DEVELOPMENT_GUIDELINES.md) for changes and reviews. Run the applicable [tests](TESTING_STRATEGY.md). Report security-sensitive findings privately and avoid posting personal data, secrets or realistic operator exports. Update docs alongside interfaces and use [Decisions](docs/DECISIONS.md) for lasting changes.
